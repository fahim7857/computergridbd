    System Design · Fault-Tolerant & Sandboxed Architecture

    Platform Architecture & Node Resilience

    Designed for intermittent consumer hardware: when a contributor shuts down their PC, the verification engine detects missed heartbeats and safely reschedules workloads.

    → → → → → →

    01. GPU Contributor Agent

    Runs safely in user space on Windows or Linux gaming PCs and workstations. Reads read-only GPU telemetry (model, VRAM, temperature, utilization), opens an outbound TLS connection, and executes workloads only inside isolated containers.

    Handling Intermittent GPU Availability

    Unlike traditional data centers, personal PCs turn off unpredictably when owners game, sleep, or experience power interruptions. The Uptime Verification Engine expects periodic heartbeats every few seconds.

    • Missed heartbeats past the grace window immediately mark the node Offline in the GPU Registry.
    • Reward accrual pauses at the last verified heartbeat—offline hours never count.
    • The Resource Orchestration Engine routes new or checkpointed tasks to remaining online nodes.

    Production Security & Deployment Requirements

    This web application is a frontend prototype. A live production deployment will require strict isolation and verification infrastructure:

    • Signed, sandboxed GPU contributor agent with no arbitrary host code execution.
    • Backend authentication, mutual TLS, and scoped API access control.
    • Containerized / microVM workload isolation and deterministic resource scheduling.
    • Cryptographic uptime verification, payment processing, and abuse prevention monitoring.

    Vision & Roadmap · Originated in Bangladesh

    Building Accessible AI Infrastructure From Bangladesh

    Thousands of capable GPUs sit idle in gaming rigs, university labs, and creative workstations across Bangladesh while local AI startups struggle with expensive foreign cloud billing. ComputeGrid BD aims to turn distributed local hardware into a resilient, transparent compute fabric.

    Phase 1 Planned

    GPU Agent and Uptime Monitoring MVP

    Lightweight cross-platform desktop agent, hardware telemetry reporting, and heartbeat uptime verification backend.

    Phase 2 Planned

    Initial Bangladesh GPU Contributor Pilot

    Closed cohort onboarding for PC owners in Dhaka, Chattogram, and Sylhet to validate intermittent scheduling and local payout workflows.

    Phase 3 Planned

    Compute Marketplace and Developer API

    Containerized job dispatch, unified REST API for startups, and transparent VRAM/price discovery marketplace.

    Phase 4 Planned

    Global Distributed GPU Network

    Multi-region federated orchestration connecting emerging-market compute pools with global AI inference demand.
